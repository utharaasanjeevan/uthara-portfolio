# Personal Portfolio

A responsive, single-page personal portfolio with:
- Light/dark theme toggle (preference saved in browser)
- Smooth anchor scrolling and scroll-reveal animations
- Animated timeline connector
- Responsive mobile navigation
- ChildConnect featured project section
- LinkedIn, GitHub and email contact links

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Personalise before publishing
Open `index.html` and replace:
- `YOURNAME` / `Your Name` / `YOUR NAME`
- `your.email@example.com`
- `utharasmenon`
- `utharaasanjeevan`
- About, education, skills and project descriptions with your accurate details

The current skills and timeline are editable starter content. Do not publish placeholders as-is.

## Deploy
Upload the folder to GitHub, then import the repository into Vercel or Netlify. The site is static, so no backend is required.
